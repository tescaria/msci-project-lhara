# LhARA Particle Transport Simulations

This repository contains input files, simulation configurations and analysis scripts for particle transport studies within the **Laser-hybrid Accelerator for Radiobiological Applications (LhARA)**  MSci project.

## Repository Structure

- **`PoPLaR-gaussian.csv`** – input file for the [LhARA Linear Optics (LLO)](https://github.com/ImperialCollegeLondon/LhARAlinearOptics) repository, used to generate the initial particle distribution in `.dat` format.

- **`dat_ascii_files/`** – contains the generated `.dat` phase-space files and their corresponding `.phsp` and `.header` files. The latter are produced using `dat_to_ascii.py` and are used as particle source inputs for OpenTOPAS and Geant4 simulations.

- **`water_phantom.txt`** – water phantom geometry configuration used in the TOPAS simulations.

- **`Geant4Validation/`** – Geant4 validation simulation, including the geometry, physics configuration, particle source and scoring implementation.

- **`dose_energy_csv/`** – Dose and energy deposition data generated by the TOPAS and Geant4 simulations.

- **`dat_to_ascii.py`** – Converts the LhARA `.dat` phase-space files into `.phsp` and `.header` files for use in the simulations.

- **`plotDepthDose.py`** – script for plotting and analysing depth-dose distributions

## Geant4 Validation

To build the Geant4 validation simulation:

```bash
cd Geant4Validation
mkdir build
cmake -S . -B build
cmake --build build -j$(nproc)
```

To run a simulation using a macro:
```bash
./build/Geant4Validation macros/run.mac
```
